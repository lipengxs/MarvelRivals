# Marvel Rivals patch-to-action runbook

Target: publish a source-linked decision record within 24 hours of an official update.

## 0–2 hours: capture the source

1. Save the official URL, publisher, original publication time, access time, named version, platform scope and exact quoted change.
2. If the source does not name a version or scope, record that gap as Unconfirmed.
3. Create the permanent route under patches using the official version or date slug.

## 2–8 hours: classify without guessing

Create five explicit sections:

1. Official source and original date.
2. Confirmed changes: heroes, Team-Up, maps/modes, or other systems.
3. Affected site pages: exact hero, Team-Up, Composer, Tracker or guide URLs.
4. Editorial recheck list: what readers should verify before acting.
5. Unverified player impact: do not write Meta, counter, win-rate or performance conclusions here.

## 8–24 hours: publish and link

1. Add the page to sitemap with an honest lastmod date.
2. Link the patch page from Season Hub and only from hero or Team-Up cards actually named by the official source.
3. Update a hero decision card's patch field only when the source directly applies to that hero.
4. Add a revision-history entry and reviewer date.
5. Validate canonical URL, source link, mobile layout, noindex state, and external-link rel attributes.

## Monitoring

At 14 and 28 days, compare GSC by page and query against GSC_BASELINE_2026-07-04.md. Watch Tracker CTR, Season Hub discovery, Team Composer submissions, source clicks and non-Tracker organic clicks. Do not reverse a source-correct update because of one day's ranking movement.
