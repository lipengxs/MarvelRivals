# Season decision source register

Last reviewed: 2026-07-29  
Publisher identity: Marvel Rivals Independent Fan Guide

## Eligible sources

| Scope | Source | What it may establish | Rule |
| --- | --- | --- | --- |
| Hero roster and role | Existing heroes-official-data.js records, each record's source URL and release date | Official profile reference and role label | Do not infer current balance, counter, win-rate, or Team-Up strength. |
| Team-Up archive | Existing heros-team.js | Historical discovery reference only | Do not present a pairing as currently available until a dated official source is added. |
| Legacy hero abilities | Existing heros-data.js | Historical ability detail | Do not use numeric ability values in a season decision conclusion without version and official source review. |
| Patch record | Official Marvel Rivals channels | A named update only when the exact URL, original date, scope and review date are recorded | A patch page must leave unknown player impact as unverified. |
| Third-party tracker | Provider's visible data page | The provider's own stated scope only | Require patch, mode, platform, rank range, sample size and collection period before using a figure. |
| Search and site analytics | GSC and GA4 aggregate reports | What readers search for and which content needs clearer answers | Never use demand or click data as a hero-strength, win-rate or player-performance claim. |

## Required fields by data type

| Data type | Required fields before use in a decision claim |
| --- | --- |
| Official roster, role or rule | Source URL, original source date, review date, applicable version/platform, exact scope. |
| Patch change | All official fields plus named affected pages and a separate Unconfirmed section for player impact. |
| Team-Up | Dated official source, applicable version/platform, named heroes, review date. A historical archive alone is insufficient. |
| Third-party observation | Provider URL, version, mode, platform, rank range, sample size, collection period and access date. |
| Editorial checklist | Framework version, review date and a visible statement that it is not a ranking or prediction. |
| Player-selected context | The selected context only; do not request or retain account, client, UID or match-history data. |

## Evidence labels shown to readers

- **Official documented fact:** directly supported by a dated official source.
- **Editorial decision framework:** a transparent planning method; never a claim about live win rate, Meta or counters.
- **Player context:** an in-browser choice used to tailor a checklist, not stored performance data.
- **Third-party observation:** optional external context that is unusable unless its methodology is visible.

## Freshness policy

- Review official profile fields after any official roster, role, ability, mode or Team-Up update.
- Review patch records on publication day; unknown impact remains Unconfirmed.
- Do not publish an external figure without a collection period; treat unknown-version figures as expired.
- Review editorial frameworks every 90 days and after a documented rule change.

## Publication gate

Every hero-specific or patch-specific decision claim needs: source URL, original source date, reviewed date, applicable version/platform, and a visible separation between official fact and editorial interpretation. If one is missing, publish a source-review note or state Unconfirmed; do not fill the gap with a tier list or derived statistic.
